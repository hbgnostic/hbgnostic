## Selected Projects

**[Traceport Overlay](https://traceport.io)** — Multi-tenant blockchain attestation API. Novel HMAC-based hierarchical key derivation, PushDrop attestation engine, UTXO management, real-time P2P block header sync. Deployed on Google Cloud Run with Cloud KMS. TypeScript + Go services.

**[TracePort for Charities](https://traceport.io/charities)** — Donation tracking platform with blockchain-verified attestations for audit and donor transparency. Includes a Flask/Python onboarding tool that parses charity documentation with AI assistance. Next.js 15, Prisma, PostgreSQL (Supabase), Vercel.

**Vela** — Production BRC-100 wallet implementation exposing micropayment APIs for any application. Runs on Cloud Run with Cloud KMS. Includes anomaly detection engine with Z-score analysis and Telegram alerting.

**[Daily BSV Intel Report](https://t.me/bsvintel_bot)** — Automated blockchain intelligence platform scanning 144 blocks of transaction data daily. Custom analytics pipeline, 3-layer orthogonal script taxonomy, whale detection, mining intelligence. 55+ Telegram subscribers. Self-operated on GCP Compute Engine with systemd and n8n automation.

**[Vela](https://velareadings.com)** — AI-powered SaaS for astrologers. Custom astronomical computation, SVG chart rendering, Claude API with streaming and prompt caching. Built from 30 years of personal practice in the domain.

**[TracePort FSMA Prototype](https://freshtrace.io)** — FDA FSMA 204 food traceability compliance application built on the Traceport Overlay API. Targets sustainable and organic food distributors.

**[The Circle Classroom](https://circleclassroom.com)** — Cohort-based LMS. Real-time Firestore architecture, privacy-controlled journaling, gamified practice modules, configurable notifications. Live with an active cohort.

**[Bitcoin Teaching Tool](https://bitcoin-teaching-tool.vercel.app)** — Interactive BSV education platform with a custom Script interpreter, opcode explorer, Merkle tree visualizers, and 30+ lessons. Monaco editor, D3.js, Next.js.
